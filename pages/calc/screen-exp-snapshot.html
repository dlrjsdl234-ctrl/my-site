경험치 시작/종료 비교 측정기

실시간 추적 대신 시작 화면과 종료 화면의 경험치 바 차이만 비교합니다.

사용법
  1. `화면 선택`으로 게임 화면을 선택합니다.
  2. 하단 미리보기에서 경험치 바 영역을 드래그해서 지정합니다.
  3. 초록색 진행 영역과 회색 빈 영역만 감싸도록 잡아 주세요. 레벨 표시나 경험치 숫자 텍스트는 포함하지 않아도 됩니다.
  4. 영역을 다시 잡으려면 `영역 지우기`를 누른 뒤 다시 드래그합니다.
  5. 시작 레벨, 종료 레벨, 모래시계 레벨, 자동 측정 시간을 확인한 뒤 `측정 시작`을 누릅니다.
  6. `측정 시작`을 누르면 시작 캡처가 즉시 저장되고, 설정 시간이 지나면 종료 캡처와 계산이 자동으로 진행됩니다.
  7. 측정 중에는 경험치 바 영역 위에 마우스 포인터를 두지 마세요. 포인터가 캡처 영역에 겹치면 픽셀 인식이 흔들릴 수 있습니다.
  8. 레벨업이 있었다면 종료 레벨을 직접 입력해 주세요. 이 페이지는 LV 영역을 따로 인식하지 않습니다.
  9. 측정 결과를 맹신하지 말고 2~3번 반복 측정해서 비교해 주세요.
  10. 캡처 방식이기 때문에 종료 캡처 경험치 - 시작 캡처 경험치를 직접 하셔도 됩니다.
영역 지정 예시

예시처럼 경험치 바의 초록색/회색 색 띠만 감싸도록 선택하면 시작/종료 캡처 이미지도 해당 영역만 잘려서 표시됩니다.

화면 선택 후 경험치 바 영역을 드래그하세요.
