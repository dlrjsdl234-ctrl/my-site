경험치 화면 측정기 하이브리드

경험치 바를 자동으로 찾고, 필요할 때만 직접 조정합니다. 화면 이미지는 서버로 전송되지 않습니다.

사용법
  1. `화면 선택`으로 게임 화면을 선택합니다.
  2. 화면 아래쪽 미리보기가 나오면 경험치 바 영역을 자동으로 찾습니다.
  3. 자동으로 잡힌 빨간 영역이 경험치 바의 초록색 진행 영역과 회색 빈 영역을 감싸는지 확인합니다.
  4. 자동 탐색이 빗나갔다면 `영역 자동 찾기`를 다시 누르거나, 빨간 영역을 직접 드래그해서 조정합니다.
  5. 한 번 선택한 뒤에는 영역 안쪽을 드래그해서 이동하고, 상하좌우 손잡이로 크기를 조절합니다. 돋보기의 굵은 십자선이 조절 중인 기준선입니다.
  6. 다시 선택하려면 `영역 지우기` 버튼이나 `Delete` 키로 영역을 지웁니다.
  7. 측정 중에는 경험치 바 영역 위에 마우스 포인터를 두지 마세요. 포인터가 캡처 영역에 겹치면 픽셀 인식이 흔들릴 수 있습니다.
  8. 현재 레벨, 모래시계 레벨, 측정 시간을 확인한 뒤 `측정 시작`을 누릅니다. 명확한 지표 수집을 위해 3분 이상 측정을 권장합니다.
  9. 측정 중에는 여러 프레임의 중앙값을 사용하고, 흔들리는 샘플은 자동으로 제외합니다.
  10. 레벨업 시 자동으로 다음 레벨로 넘어가지만, 이펙트가 심하면 오인식 가능성이 있습니다. 해당 부분을 고려해서 사용해 주세요.
  11. 측정 결과를 맹신하지 말고 2~3번 반복 측정해서 비교해 주세요.
자동 탐색 후 조정 예시

예시처럼 빨간 선은 경험치바의 초록색/회색 색 띠만 감싸면 됩니다. 숫자, 아이콘, 채팅, 이펙트는 영역에서 제외하세요.

화면 선택 후 아래쪽 미리보기에서 경험치 바 영역을 드래그하세요.

이 페이지는 기존 경험치 계산기의 색상 비교 방식과 다르게, 선택 영역 안의 초록색 픽셀 밀도를 열 단위로 분석합니다. 화면 캡처 프레임은 서버로 전송되지 않으며 브라우저 메모리 안에서만 처리됩니다.
